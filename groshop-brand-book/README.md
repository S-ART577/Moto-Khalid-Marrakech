# GROSHOP Brand Book — V3

`index.html` is the V3 brand book (4 octobre 2026). Open it in a browser with the `assets/` folder next to it, or use the shared claude.ai link.

V3 consolidates:

- the V2 identity (`GROSHOP_DESIGN_SYSTEM_V2.md`, August 2026),
- every rule added afterwards in the Groshop Design System (campaign motifs, button states and motion, light UI mode, status colors, Lucide icons, numerals, templates, the Reel/Darija content system),
- two decisions: tagline hierarchy and the hero-weight split (Light on campaigns, Bold on promos),
- the October audit fixes (measured contrast, logo catalog, symbol color on dark, canvas type minimums, story safe zones, price format above 999).

`assets/` holds web-sized copies of the official logo PNGs, the canonical campaign cover, and two V3 symbols for dark backgrounds (`symbol-arrow-red.png`, `symbol-star-red.png`) cut from the official lockups until vector exports are available.
